## 关键验收概念

**采集覆盖率** = 实际获得音频样本所对应时长 / 计划记录时长。睡眠与用户暂停是否计入分母必须在报告中说明。仅靠“服务在运行”不能计算。

**转写覆盖率** = 已转写且可追溯的人声时长 / 标注人声时长。需要人工样本；不把 ASR 输出字数当覆盖率。

**转写延迟** = 片段结束到正文可读的时间。分别记录手机推理、排队、网络和中继处理。

**重复率** = 同一稳定片段出现多次业务副本的比例。事件投递重试不应创建第二份原文。

**隐私可控性** = 用户能找到暂停、睡眠、同步授权、删除和缺失记录，且实际状态与页面一致。

所有阈值需经过设备基线与使用需求确定。本版不给出虚构的准确率、续航、延迟或模型性能指标。
